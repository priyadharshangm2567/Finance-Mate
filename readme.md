FinMate AI

FinMate AI is a personal finance web application that helps users track expenses, analyze spending patterns, and predict next month's expenses using machine learning.

  Features
- Expense analysis
- Financial health score
- Expense prediction
- AI recommendations
- CSV/Excel bank statement upload
- Interactive charts
- PDF report generation

  Tech Stack
- React.js
- FastAPI
- Python
- Scikit-learn
- Pandas
- Chart.js
